# to-my-mother 👵💖

A nostalgic and accessible game suite designed with love for my mother (born in 1941).

[**Play Now Live 🚀**](https://bar4si.github.io/to-my-mother/)

## 🌟 Features

- **Game Suite Hub**: A central menu to select between different games and challenges.
- **Dynamic Word Search**:
  - Over **50,000 unique word combinations** generated from a vast pool.
  - Three difficulty levels: **Beginner**, **Intermediate**, and **Expert**.
  - **Expert Mode**: Includes diagonal words for an extra challenge.
- **Global Scoring System**: Earn points for every victory (1, 5, or 10 points based on difficulty).
- **Senior-Friendly UX**:
  - High contrast (7:1 ratio) for better visibility.
  - Large hit targets (60px) for easy interaction.
  - Straight-line selection lock to help with motor precision.
## 🕹️ Games Included
- **🔍 Word Search**: Over 50,000 unique combinations across three difficulty levels.

## 🛠️ Tech Stack

- **Framework**: React + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Persistence**: LocalStorage

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bar4si/to-my-mother.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### Deployment

This project is configured for **GitHub Pages**. To deploy:

1. Push your code to the `main` branch on GitHub.
2. Go to your repository settings > **Pages**.
3. Under **Build and deployment > Source**, select **GitHub Actions**.
4. The site will be built and deployed automatically.
