# 📋 Plano de Expansão (TODO) - Para Mamãe 👵💖

Este documento contém o roadmap de atividades, agora focado na **Autonomia e Conexão** para uma senhora que mora sozinha. O objetivo é transformar o app em um companheiro diário que ofereça segurança, orientação e afeto.

## 🏆 Ranking de Prioridade (Foco: Morar Sozinha)
*Priorizando a segurança emocional e a orientação temporal.*

| Prioridade | Atividade | Foco Terapêutico | Benefício para quem mora só |
| :--- | :--- | :--- | :--- |

## 🚀 Ideias para Suporte à Autonomia

### 🏠 Morando Sozinha (Segurança e Presença)
- [ ] **📅 Calendário de Hoje**: Uma tela inicial simples que diz: "Hoje é Quinta-feira, dia de [Evento/Livre]". *Foco: Orientação espacial e temporal.*
- [ ] **💌 Mensagem dos Filhos**: Um espaço onde você pode deixar uma frase ou "cartinha" fixa para ela ler todo dia. *Foco: Combater o sentimento de solidão.*
- [ ] **🚨 Atalho de Emergência**: Um botão grande (ex: "Ligar para [Seu Nome]") que ela pode usar rapidamente se precisar de ajuda.

### 🧠 Estímulo de Rotina (Neuropsicologia)
- [ ] **💊 "Já tomou o remédio?"**: Um check-list visual e interativo para ajudá-la a controlar a rotina de saúde. *Foco: Memória episódica e autonomia.*
- [ ] **🥘 Prato Saudável**: Jogo de montar uma refeição equilibrada no app. *Foco: Manutenção de hábitos de autocuidado.*

### 🎨 Novas Atividades Cognitivas
- [ ] **🕒 Relógio Analógico**: Exercício para identificar a hora em ponteiros. *Foco: Preservar leitura de relógios clássicos.*
- [ ] **🛒 Lista de Compras**: Memorizar 3 itens e encontrá-los em uma "prateleira" virtual. *Foco: Memória de trabalho.*

### 🛠️ Melhorias de Acessibilidade (Foco Solo)
- [ ] **🖐️ Filtro de Toque Acidental**: Ignorar múltiplos toques para quem tem tremores leves.
- [ ] **🔊 Feedback por Voz**: O app "fala" as vitórias e lê as frases importantes, fazendo companhia.
